# Музика

Собствени композиции, написани за @podredeno.bg (`compose.py`) и озвучени със
звуковата библиотека FluidR3_GM (лиценз MIT). Няма чужди авторски права.

| файл | настроение | темпо |
|---|---|---|
| utro.m4a | спокойно, електрическо пиано | 80 |
| krachka.m4a | бодро, арфа и маримба | 112 |
| fokus.m4a | тихо, фон за размисъл | 68 |
| seria.m4a | топло, китара и звънчета | 96 |
| start.m4a | нарастващо, пиано и струнни | 100 |

Всички са ~45 сек, около -14 LUFS.
